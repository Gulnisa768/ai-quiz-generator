# AI Quiz Generator

## Project Description
AI Quiz Generator generates questions from paragraphs using a fine-tuned T5 deep learning model.

## Technologies Used
- Python
- T5 Transformer
- Hugging Face
- Streamlit
- PyTorch

## Hugging Face Model
https://huggingface.co/Gulnisa/ai-quiz-generator

## Features
- Enter a paragraph.
- Generate questions automatically.
- Generate multiple questions using AI.

## Run Locally
pip install -r requirements.txt

streamlit run app.py
